FĂRĂ CUTIE NEAGRĂ

Probabilități pe care le poți inspecta.

01 / DATE

Doar înainte de start

Folosim scoruri finale mai vechi decât startul cu minimum 3 ore. Nu folosim statistici live sau clasamente actuale pentru predicții istorice.

02 / MODEL

Goluri → probabilități

Poisson, ponderare temporală și ajustare către media ligii. O singură matrice de scoruri produce piețele 1X2, șansă dublă, goluri și ambele marchează.

03 / SELECȚIE

Dreptul de a refuza

Minimum 8 rezultate per echipă și unul în ultimele 90 de zile. Pragul de 85% este pentru selecțiile individuale din Match center. Generatorul de bilete are propriul prag, afișat explicit.

04 / VALIDARE

Estimarea nu este dovadă

Modelul este necalibrat. Probabilitățile combinate folosesc o aproximație de independență. Nici un plan, nici un backtest nu garantează rezultate viitoare.

Biletele reale folosesc cotele 1X2 disponibile în FlashScore. Nu inventăm cote pentru piețe fără ofertă. Datele demo, inclusiv cotele lor, sunt sintetice. Nu sunt implementate mize automate.
